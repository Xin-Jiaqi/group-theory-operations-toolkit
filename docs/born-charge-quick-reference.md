# Born 有效电荷与滑移电耦合速查表

完整推导见 [born-effective-charges.md](born-effective-charges.md)，可机读数据见 [born-charge-reference.json](born-charge-reference.json)。

## 先确定查询对象

| 已知信息 | 可以确定什么 | 不能直接确定什么 |
|---|---|---|
| 原子的位点群及其实际取向 | 该原子 BEC 的允许分量和相互关系 | 数值、符号，以及其他原子的关系 |
| 空间操作、原子置换及电中性 | 全部原子 BEC 的联合允许空间 | 微观数值与切换能垒 |
| 结构对称性及指定模式的表示 | 模式有效电荷的允许分量、驱动方向 | 外场是否足以完成翻转 |

采用原始 VASP OUTCAR 约定：$Z_{ij}$ 的第一个指标为极化/电场，第二个为位移/受力。因此 $E_z\to F_x,F_y$ 应读取第三行的第一、二列。原子 BEC 一般不对称；不同软件可能采用转置约定，参见完整推导的参考文献 [1,2]。

## 六种原子张量形式

各字母为独立参数；“允许”不保证数值非零。以下是**位点群**表，不是给整个中性原胞赋一个总 BEC。

$$
\begin{aligned}
A&=\begin{pmatrix}a&b&c\\d&e&f\\g&h&i\end{pmatrix},&d_A&=9,\\
B&=\begin{pmatrix}a&b&0\\c&d&0\\0&0&e\end{pmatrix},&d_B&=5,\\
C&=\operatorname{diag}(a,b,c),&d_C&=3,\\
D&=\begin{pmatrix}a&b&0\\-b&a&0\\0&0&c\end{pmatrix},&d_D&=3,\\
E&=\operatorname{diag}(a,a,c),&d_E&=2,\\
F&=aI_3,&d_F&=1.
\end{aligned}
$$

**参考坐标：主轴为 $z$，单斜镜面为 $xy$，次级二重轴为 $x$。** 实际材料应将操作和张量同步旋转；尤其 $m_z$ 与 $m_{xz}$、$C_{2z}$ 与 $C_{2x}$ 不可混用。表中“交叉元”一列仅针对这一参考坐标。

## 面外电场驱动孤立双层相对滑移

假设：双层在 $xy$ 平面、固定晶胞、仅两层、中性、刚性相对平移 $\mathbf s=\mathbf u_T-\mathbf u_B$。定义

$$
\zeta_a=\frac12\left(\sum_{T}Z_{\kappa,za}-\sum_{B}Z_{\kappa,za}\right),
\quad \mathbf f_s^{(E)}=eE_z\boldsymbol\zeta.
$$

中性声学求和规则满足时，$\zeta_a=\sum_T Z_{\kappa,za}$。不应只看某一个原子的交叉元。

令 $A_g$ 为操作的面内 $2\times2$ 块，则 $A_g\boldsymbol\zeta=\boldsymbol\zeta$。完整分类只有三种：

| 所有面内操作组成的群 | 模式允许空间 | 孤立双层点群及取向 |
|---|---|---|
| 仅恒等 | 面内任意方向，2 维 | $C_1$；水平镜面 $C_s^{(h)}$ |
| 恒等及关于同一条面内直线的反射 | 沿该直线，1 维 | 竖直镜面 $C_s^{(v)}$；二重轴沿该线的 $C_2$；主轴沿该线且含水平镜面的 $C_{2v}$ |
| 其他 | 禁止该一阶耦合，0 维 | 其余保持层平面的点群及取向 |

这是一套**模式电荷**表：它与原子表不同，因上下层交换时相对滑移多一个负号。特别是 $m_z$ 可以禁止固定在镜面上的原子交叉元，但不禁止其所交换的两层的相对模式电荷。

### 常用操作逐项速查

| 操作 | 面内块 $A$ | 模式约束 |
|---|---|---|
| 恒等 $E$、水平镜面 $m_z$ | $I_2$ | 两个分量均允许 |
| $m_{xz}$、$C_{2x}$ | $\operatorname{diag}(1,-1)$ | 只允许 $\zeta_x$ |
| $m_{yz}$、$C_{2y}$ | $\operatorname{diag}(-1,1)$ | 只允许 $\zeta_y$ |
| $C_{2z}$、反演 $I$ | $-I_2$ | 两个分量均为零 |
| $C_{3z},C_{4z},C_{6z}$ | 非平凡面内旋转 | 两个分量均为零 |
| 多个操作 | 分别施加 | 取所有允许空间的交集 |

不能将立方点群直接作为固定层法向的孤立二维双层群。若操作混合层法向与面内方向，当前二维滑移求解器会拒绝输入。

## 最小使用示例

```python
import numpy as np
from group_theory_operations.born_effective_charges import (
    point_group_born_space, sliding_born_space,
)

# 这里 C3v 必须是所研究原子的位点群。
print(point_group_born_space("C3v").dimension)  # 2

# 二重轴实际沿面内 x，不能用默认主轴沿 z 的 C2 条目代替。
r = np.diag([1., -1., -1.])
space = sliding_born_space([r])
print(space.dimension)       # 1
print(space.allowed_mask)    # [True, False]
```

对称性筛选只提供局域允许性。高对称端点的模式电荷为零，不代表中间态、畴壁或对称性破缺后的路径均为零；非零模式电荷也不构成可切换性的充分条件。详见完整推导第 8 节及文献 [3,4]。
